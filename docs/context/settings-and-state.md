# Settings and shared state

What the panel, decoder and discovery share, settings, keys, feature switches, themes and the log. Code and tests outrank this page.

| Path | Holds |
| --- | --- |
| `crates/core/src/controls.rs` | State shared by panel, decoder and discovery (stop, model switch, whether a model runs and why the GPU wasn't used, notices for the panel, whether to check for updates and the update found, dictation only mode, whether to tell voices apart in apps and at the mic (`voices_apps`, `voices_mic`; `voices_for(mic)` is one source's switch, `voices_wanted` either, `keep_voices` drops a line's voice where its source's switch is off; `voices_across_apps`; `voice_place(app)` is the `Place` a stream's voices are recognised in; `saved_voices` is the shared `SavedVoices`, in memory until N-2; `name_voice(app, voice, name)` asks the decoder to name a speaker, refusing a blank name with a message for the panel; `SavedVoices::rename` does too), the macro mode chosen by voice or a `mode` step (`mode`/`set_mode`), the hotwords the model listens for, the mic lines said without the dictation key waiting for listening macros (`queue_mic_line`, kept only while a macro listens; `take_heard`), sensitivity, blocked apps: until Kiku quits or always, the word rules) and the Discord-style sensitivity gate; the gate also says when silence can be left out (after 2 s of it) |
| `crates/core/src/keybinds.rs` | The captions key and command keys: names, validation (nothing that breaks typing, no clashes, no Win+L) and their settings lines (the commands include `Palette`, Ctrl+Win+M; `Command::action` gives the `KikuAction` a command key stands for, none for Quit; `dictate_words` says how the key dictates, "Hold Ctrl+Win to dictate") |
| `crates/core/src/settings.rs` | Settings saved to `%APPDATA%\kiku\settings.txt`, including how names show on lines (`labels.you`, default every-line, and `labels.speakers`, default turns: `LabelStyle` every-line, turns, tags, colour, badges, blocks; captions mode takes every-line and badges as they are and the others as tags), the save mode (auto: every finished line, optionally only your mic, deleted after a number of days, default 30; manual: only what the save buttons save, kept) the panel's auto-fold time (off, 1, 2, 5 or 10 min; default 2), what the block button does (ask, or block until quit or always without asking), how your lines in an app's section are marked (`your_lines`: italics, highlight or both; default highlight), whether to check for updates (default on), the panel's background and text opacity (`Opacity`: `window_opacity`, 10 to 100%, and `text_opacity`, 25 to 100%; default 100) and a second pair while it is locked (`locked_window_opacity`, `locked_text_opacity`; unsaved, the same as unlocked), dictation only mode (`dictation_only`, default off), dictation (`dictation.key` `hold`|`toggle`, `dictation.release_delay` 0 to 2000 ms, `dictation.stop` comma-separated stop phrases, default `that's all Kiku`; `DictationSettings`, read and written as `WordSettings` is), where word rules and transforms apply and whether the model listens for the `@` words and how strongly (`words.rules`, `words.transforms`, `words.hotwords`, default on, `words.strength`: the strength of the `@` words without their own, 0.5 to 4, default 1.5), the app's theme (`theme = night`, and the Custom theme's `custom.*` lines) the apps blocked always (a `blocked = <app>` line each) and the apps pinned to get your lines (a `pinned = <app>` line each), where the model runs (`engine.where = this-pc | host`, `engine.host = <code>`) and whether this PC shares its models (`host.on`) and whether to tell voices apart in apps (`voices.apps = on|off`, default on) and at the mic (`voices.mic`, default off; 0.5's unreleased `voices` line is ignored), and `voices.recognise` (`each-app` by default: speakers are numbered per app; `across-apps`: one numbering, a voice recognised in any app). The wake word listening macros wait for (`macros.wake`, empty by default), whether macros may run programs and from anywhere (`macros.run`, `macros.run_anywhere`, off) and the built-in mode phrases turned off (`macros.phrases`, ids: command normal off on say). Written atomically (temporary file, then rename) |
| `switches.toml`, `crates/core/src/switches.rs` | Feature switches, one list for the project (public). `switches::enabled(name)`: a switch starts `off` and off is today's app, a name not in the list is off (a debug build also asserts); `default = "on"` ships it; after its release the code for off is deleted and the name goes in `tombstones`, never reused. `KIKU_FLAGS=a,b` turns off switches on in debug builds only; release builds read the list alone. `mise run ci:switches` checks the list (the cap per area is a proposal) |
| `crates/core/src/theme.rs` | The app-wide themes (Night, the default, Day, Lagoon, Meadow, Blossom, Graphite, and Custom), each styling the panel, the settings window and captions mode. A theme's editable `Colours`: background, accent, captions pill and text. `Themes` holds the theme chosen and the one Custom theme (a base preset and its colours): editing a preset's colours copies them into Custom (replacing it) and shows Custom, so presets never change and picking one is the reset; whether the theme is light comes from its background. Captions colours picked by hand in older settings (`subtitles.pill`/`text`) become Custom |
| `crates/core/src/log.rs` | Diagnostic log at `%APPDATA%\kiku\log.txt` (previous run in `log.old.txt`): sources found/lost, capture and stream errors, model loads, decoder lag, why Kiku quit (`quitting: <how>`, then `closed` once done; a log ending without them means it was ended from outside or crashed in native code, which Windows' Application log records) and a panic's message and place. The app has no console, so check here first. Each message is written at most once a minute (repeats are counted); the log stops at 1 MiB per run |
